This project was developed as part of the Mobile Application Development Practical Tutorial 03

Application Purpose: We built a cross-platform mobile application using React Native and Expo named "StudentHub".

Core Features & Architecture: Implemented bottom tab navigation nested with a stack navigator using Expo Router route groups (home). Created a main dashboard screen (index.tsx) using ScrollView and interactive Pressable components with dynamic press feedback, a digital ID card screen (details.tsx) featuring local image assets and profile details, and a live clock screen (clock.tsx) that simulates a background task using React's useEffect and setInterval hooks for real-time updates. Integrated vector icons via @expo/vector-icons and utilized core UI components styled with StyleSheet.
